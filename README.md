# Проект «плагин» — разработка комплекта регламента

Здесь ведётся **версия разработки** нашего регламента: правила-проверки, сторож
(плагин ДСХ), навыки процедуры и свои инструменты коммита и закрытия задачи.
Работает регламент в проекте ПРИЗМА — там лежит **развёрнутая копия**, её читают
ДСХ, ворота и стражи.

Решение и правила: vault ПРИЗМЫ, заметки «Разработка регламента — отдельный проект»
(`docs/vault/архитектура/`) и «Переезд комплекта регламента в проект «плагин»»
(`docs/vault/задачи/`).

## Раскладка

| Папка здесь | Что это | Куда разворачивается в ПРИЗМЕ |
|---|---|---|
| `hooks/` | правила-проверки регламента (Python и shell) | `.reglament/hooks/` |
| `plugin/` | сторож: ворота правок, карточка согласования, конец хода | `.dsh/plugin-reglament/` |
| `skills/reglament/` | навык процедуры задачи (`/reglament`) | `.dsh/skills/reglament/` |
| `skills/memory-cleanup/` | навык уборки памяти | `.dsh/skills/memory-cleanup/` |
| `tools/` | свои инструменты ДСХ: коммит, закрытие задачи, склад проверок, измеритель памяти, сборка слоя пресета | `.dsh/tools/` |

Навык `poligon-health` (проверка стенда) и разведочные остатки ДСХ
(`.dsh/hooks/`, `.dsh/plugin-probe/`, `.dsh/regen-preset.ps1`) в комплект не входят —
они про стенд, а не про регламент.

**Версия сторожа** — в `plugin/package.json` (поле `version`).

## Развёртывание в проект ПРИЗМА

```powershell
python deploy_to_project.py            # скопировать изменения в проект
python deploy_to_project.py --check    # только сверить, ничего не писать
```

`--check` отвечает «различий нет» либо перечисляет, что разошлось, и возвращает
код 1. Скрипт только копирует и добавляет: лишние файлы в проекте он не удаляет.

Порядок работы: правим здесь → `--check` → разворачиваем → коммит в ПРИЗМЕ со
ссылкой на заметку vault. Правка развёрнутой копии напрямую запрещена (кроме
аварийной починки — и тогда тем же изменением здесь).

## Проверки перед развёртыванием

```powershell
node plugin/self-test.mjs     # самопроверка сторожа: перевод команд, ворота карточки, конец хода
```

Правила-проверки (`hooks/`) и инструменты (`tools/`) гоняются в проекте ПРИЗМЫ:
там есть vault, табло задачи и история.
