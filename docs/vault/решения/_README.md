# Журнал решений

Здесь стратегические решения — то, что меняет планы, а не
чинится правкой.

## Чем отличается от задач

У задачи есть завершение: сделана и закрыта. У решения
завершения нет — только отмена или пересмотр. Решение
«переводим проект на другой инструмент» действует, пока его
не отменят, и влияет на все последующие задачи.

Если держать их в одной папке, решения теряются среди
закрытых задач, и через полгода никто не помнит, почему
проект устроен именно так.

## Откуда берутся

Чаще всего — по ходу аудита. Аудит даёт результаты трёх
категорий, и путать их вредно:

- **находка** — конкретный дефект, чинится правкой;
- **осознанный долг** — известно, что плохо, решено не
  трогать; записывается, чтобы ревью не находило заново;
- **решение** — меняет планы, отменяет часть находок.

Третья категория самая незаметная и самая влиятельная:
решение «переписать этот слой» обесценивает все находки
внутри этого слоя.

## Формат записи

Один файл на решение. Обязательно:

- **что решено** — одной фразой;
- **дата**;
- **почему** — какая проблема к этому привела;
- **что отменяется** — какие задачи или находки теряют смысл;
- **чем подтвердить пересмотр** — при каких обстоятельствах
  решение стоит пересмотреть.

Последний пункт важнее, чем кажется. Решение без условия
пересмотра превращается в догму: никто не помнит, почему так,
и никто не решается изменить.
