# Правка хука завершения хода по итогам проверки

Статус: сделано
Дата: 2026-08-18

## Проблема

Проверка по первоисточнику (hooks.md скачан целиком) и живой
сбой в Self-org вскрыли четыре дефекта первой версии хука:

1. **Штамп до устного согласия.** Фаза «заметка» ставится при
   показе проекта заметки — до устного «согласовано». Хук же
   разворачивал любой ход этой фазы без упоминания
   approve_task.py, включая ход «Согласуем заметку?», и
   навязывал штамп преждевременно. Тест №1 первой версии
   закреплял эту ошибку как норму.
2. **Наблюдатель не проверялся.** Исходная жалоба пользователя
   была про забытого наблюдателя, а хук проверял только призыв
   нажать Run. Живой сбой: штамп поставлен (одобрено 21:10),
   сессия спит — наблюдателя никто не запускал.
3. **Фантомная фаза «согласование»** в ФАЗЫ_ОЖИДАНИЯ_ШТАМПА —
   в словаре фаз регламента её нет.
4. **Версия plugin.json отстала** (1.1.1 при репозитории v1.2).

## Решение

а) Ход-вопрос пропускается: «?» в последних трёх символах
   после обрезки пробелов (покрывает «?», «?»", «?)»).
   Логика: вопрос — это продолжение согласования; ловим только
   молчаливое окончание хода.
б) Reason переписан на два случая: согласование идёт → закончи
   вопросом; устное «да» получено → штамп + наблюдатель + призыв.
в) Проверка наблюдателя по background_tasks (Claude Code
   v2.1.145+, первоисточник: поле введено отличать «сессия
   закончила» от «ждёт фоновую работу»). Наблюдатель — фоновая
   команда с «task-state» в тексте. Поля нет — проверка молча
   пропускается (совместимость). Порядок проверок: сначала
   призыв, потом наблюдатель — ход с призывом и «?» на конце
   не обходит проверку наблюдателя.
г) Фаза ожидания штампа — только «заметка».
д) plugin.json → 1.2.1.
е) SKILL шаг 8: интерпретатор по ОС (Windows — python,
   macOS/Linux — python3).

## Подтверждено первоисточником (без правок)

- {"decision": "block", "reason"} — верхний уровень; reason
  «Tells Claude why it should continue» — уходит модели.
- stop_hook_active + перебивание после 8 блокировок — дословно.
- stopReason «Not shown to Claude» — верно процитировано ранее.
- statusMessage — валидное поле; timeout — секунды (600 по
  умолчанию).
- Stop не срабатывает на прерывание пользователем.
- ВАЖНО: автопересказ страницы документации дважды дал разные
  ответы (hookSpecificOutput против decision). Читать сырой
  текст, не пересказ.

## Как проверим

Прогон 12 сценариев (runner в черновике): ход-вопрос × 2 —
тихо; утверждение без призыва — блок с «вопросом пользователю»;
призыв без поля background_tasks — тихо; призыв + пустой список
— блок про наблюдателя; призыв + чужая фоновая задача — блок;
призыв + наблюдатель — тихо; stop_hook_active, малая форма,
штамп, фаза «код», пустое табло — тихо.

**Факт: все 12 прошли.** Копия установлена в Self-org (МАСТЕР
снят, компилируется); текущей задаче Self-org не мешает — штамп
там уже стоит, хук в этом состоянии молчит.
