# Матчер PowerShell в хуках контроля коммита

Статус: сделано
Дата: 2026-08-28

## Проблема

В шаблоне настроек хуков (`templates/settings-hooks.json`) обе
проверки перед коммитом — тесты (`pre-commit-tests.sh`) и ссылка
на заметку в сообщении (`check_commit.py`) — стояли только на
матчере `Bash`. Матчер сравнивает имя инструмента точно, а в
сессиях Claude Code на Windows есть и инструмент `PowerShell`:
`git commit`, выполненный через него, миновал обе проверки.
Дыра найдена в боевом проекте planapp (обход подтверждён живым
коммитом ещё 2026-08-22, тогда починили только определение
чужого репозитория, а не сам обход).

## Решение

В `PreToolUse` добавлена вторая группа с матчером `PowerShell`
и теми же двумя хуками (команды и таймауты — копия группы
`Bash`). Скрипты не менялись: оба читают из stdin-JSON только
текст команды (`tool_input.command`), имя инструмента им
безразлично, а поле у обоих инструментов одно и то же.

На системах без Windows группа безвредна: инструмента
`PowerShell` там нет, матчер просто никогда не срабатывает.

Проверка — в planapp (worktree, хуки v1.4.0 + эта правка):
прямые прогоны обоих скриптов с PowerShell-вводом (красный тест
→ блок; сообщение без ссылки → блок) и живой перехват — настоящий
`git commit` через инструмент PowerShell заблокирован
`check_commit.py`. Хуки подхватились в той же сессии, без
перезапуска.
